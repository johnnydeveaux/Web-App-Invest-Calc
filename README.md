# Web App - Invest Calc

Simple compound-growth calculator: how long until savings hit a target, given a starting principal, monthly contribution and annual return rate. Monthly compounding, deposits at the end of each month.

Works offline after the first visit and can be added to the Home Screen on iPhone/iPad (Share > Add to Home Screen) or installed from Chrome/Chromium on Linux.

All files live flat in the repo root. Served with GitHub Pages from the `main` branch, root folder.

To release a new version: bump `VERSION` in `index.html` and `CACHE` in `sw.js`.
